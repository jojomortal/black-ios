# HD texture map

`black-hd-reimagined.map` comes from [portingpete/Black-2006-Recomp](https://github.com/portingpete/Black-2006-Recomp)
(commit afb1ffd, MIT, copyright portingpete and sp00nz; licence copied in `LICENSE-portingpete`). Each line gives the
key of a game texture (FNV-1a 64 of its top level read as 64-bit words, width, height, Xbox colour format) and the
pack file that replaces it.

The pack itself is **BLACK HD Reimagined** by HD REIMAGINED, made for the PS2 version (ModDB). It is their work and
is never committed here.
